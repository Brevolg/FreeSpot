# Система оптимальной парковки

Адаптивный фронтенд для подбора свободного парковочного места по типу автомобиля и условиям поездки. Проект работает на React, TypeScript и Vite.

## Структура и запуск

Нужны Node.js 20+ и pnpm. Если команда `pnpm` не найдена, установите менеджер пакетов:

```bash
npm install --global pnpm
```

После установки закройте и заново откройте терминал, затем перейдите в папку `frontend/` (cd frontend).

```bash
pnpm install
pnpm dev
```

Откройте адрес, который выведет Vite (обычно `http://localhost:8443`). Основной экран — стартовая страница; кнопка «Найти подходящее место» открывает подбор. Для проверки сборки:

```bash
pnpm typecheck
pnpm build
```

## Что есть в интерфейсе

- стартовая страница с числом свободных мест и кратким обзором зон;
- схема парковки с занятыми и свободными местами;
- выбор типа автомобиля, потребности в зарядке и доступном месте;
- подбор подходящего места, альтернативы и маршрут от въезда;
- состояние отсутствия подходящих мест;
- адаптивная версия для телефона.

## Данные

Сейчас занятость задана в `src/parking.ts` константой `BUSY`. Это демонстрационные данные. Для реальной парковки понадобится источник текущей занятости (API или датчики), а также подтверждённые размеры мест и план проездов. Подбор в текущем проекте работает на клиенте по этим примерным данным.

В папке проекта находятся приложение целиком, его `package.json`, lockfile, Vite и TypeScript конфигурации, HTML-точка входа и публичные ресурсы. Стартовая страница находится в `src/HomePage.tsx`, схема парковки — в `src/ParkingMap.tsx`, панели выбора и результата — в `src/Panels.tsx`, состояние экранов — в `src/App.tsx`.

На первой и второй странице используется Manrope. Для заголовка «Паркуйтесь с умом» сохранён отдельный шрифт Guano Apes. В `public/fonts` также сохранены Wremena и Kazuki Reiwa для сравнения; Kazuki Reiwa создан Kazuki Kimura и распространяется по лицензии SIL Open Font License 1.1 (`public/fonts/KazukiReiwa-OFL.txt`).
